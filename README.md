# 💰 Personal Finances Analysis

## 📌 Project Overview
This project focuses on the organization and analysis of personal financial data using a relational database and data analysis tools.  
The main objective is to structure financial records into meaningful categories and analyze spending behavior over time.

The analysis includes:
- Monthly spending distribution  
- Total expenses per category  
- Outlier identification to detect atypical values  

---

## 🛠️ Technologies Used
- **Python (Pandas, Matplotlib, Seaborn)** — data cleaning, transformation and exploratory data analysis.
- **MySQL** — relational data storage, aggregation, and querying
- **Power BI** - Visualization
---

## 📄 Data Information
The project is based on a CSV file representing personal financial transactions.  
The dataset contains the following columns:

| Column | Description |
|------|------------|
| Date | Transaction date |
| Amount | Transaction value |
| Category | Expense category |
| Payment Method | Payment method used |

The CSV file is loaded into **Pandas**, where data cleaning and formatting are performed.  
After preprocessing, the data is structured into **relational tables in MySQL**.

All **SQL queries and data exploration steps** are executed and documented within a **Jupyter Notebook**, which serves as the main analysis environment.
